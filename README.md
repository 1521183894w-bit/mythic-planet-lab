# 奇幻行星实验室

以地质与气候过程生成可编辑的虚构地理。地貌工作台面向从空白绘制的区域，也支持导入现有底图。海岸、冰川、沉积和气候驱动按区域逐步接入，计算结果保留方法和版本。
