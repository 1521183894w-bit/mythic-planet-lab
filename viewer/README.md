# 行星图志 · 终图 v2

在项目根目录运行以下命令，再用浏览器打开 `figures/design/v2/globe/index.html`。

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run.ps1 python scripts\build_globe.py
```

成品是一个包含界面与纹理的 HTML 文件，可复制到另一台电脑直接打开。使用鼠标拖动、滚轮或双指缩放，单击球面读取经纬度。左栏可跳转区域，右上角可切换底图和经纬网。用键盘时，聚焦球面后按方向键、加减键和 Home 键。渲染按需刷新，浏览器 WebGL 不可用或丢失时会切换到较低显示分辨率的 Canvas 2D 绘制。

## 数据与后续细化

- 导出器复用 `scripts/design_final_map.py` 从现行 `config/design/final_map_v2.yaml` 重建终图，使用默认选项及 2048 × 1024 格网。现行配置包含旧版静态图出图后录入的 U35 主内海弧形西口。格网为等距圆柱，自北向南、−180° 至 +180°，像元中心采样。赤道格距约 19.5 km。
- 海陆轮廓是终图设计（`user_override`）。示意地形使用原设计高程着色（`visual_only`），球面明暗与边缘光仅为显示效果。比例尺按视图中心的球面弧长估算。
- 当前球面只呈现格网内容。旧版静态图上另行标注的亚格点环礁、海山等符号留待矢量叠层接入。
- 单页中嵌有独立的 `world` 数据清单，包含来源、源文件哈希、网格尺寸、图层方法与单位。后续可以保留界面与导航，接入新地形和水文输出。全局单纹理适合目前的设计尺度。区域高分辨率数据增多后，需要给渲染层接入分级瓦片，按当前视角载入所需分辨率。
