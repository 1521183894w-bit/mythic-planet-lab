# 独立项目 · 300 Ma 构造演化

**状态：暂停迭代，待单独启动。** 2026-11-05 用户决定先用原终图 v2 交付单世界的现世地理，构造演化从现世阶段验收中分离。

- **目标**：为同一个世界构建一条可解释的 300→0 Ma 历史，产出关键年代古地理、构造事件及可供岩性和成矿解释的历史数据。板块旋转可从现世重建，地壳过程需正向运行。任何得到的历史都是一种可能情景。
- **已有材料**：板块运动重建、正向引擎、事件日志、关键帧和 U22–U44 的试验与评审。U44 是已记录的末轮试验；[交接与局限](../docs/u44_pocket_partition.md)。旧任务书可由 Git 的 0ff6b2e 版本读取，保留工程记录。
- **独立交付**：区分设计事件、运动学重建和演算结果。启动时单独约定交付、工期和评审范围。为资源所需的古纬度、岩浆活动、埋藏等字段，仅在可追溯时作为历史数据使用。
- **与现世地图的关系**：阶段 1–3 使用选定的现世底图。地史候选和现世地图发生冲突时，记录差异，由用户决定是否调整既有地理。
